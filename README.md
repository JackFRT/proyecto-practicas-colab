# HT-Cactus-Museum

## Requisitos

- XAMPP
- Node.js
- Angular CLI

---

## Instalación y ejecución del sistema

### Backend (API PHP)

1. Copiar la carpeta `cactus-api` dentro de:

xampp/htdocs/

2. Abrir el panel de control de XAMPP e iniciar los servicios:

- Apache
- MySQL

---

### Frontend (Angular)

1. Colocar la carpeta `HT-Cactus-Museum` dentro de la carpeta `xampp`, al mismo nivel que `htdocs`.

Ejemplo:

xampp/
├── htdocs/
├── HT-Cactus-Museum/

2. Abrir una terminal dentro de la carpeta `HT-Cactus-Museum`.

3. Ejecutar los siguientes comandos:

```bash
npm i
ng serve
